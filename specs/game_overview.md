# Game Overview

## Game Concept

CGAA (Circle Gladiator Army Arena) is a fast-paced action tower defense game that blends 2D action gameplay with strategic tower placement. The game is designed to be played in short sessions with a low barrier to entry, making it accessible as a browser game.

## Story

Players control a young, rebellious circle tasked with defending blue-colored friends against multiple camps of blue-hating aggressors. The player must either convince enemies to stop attacking or defeat them using towers and direct combat. The ultimate goal is to defeat the king who watches from a guarded chamber.

## Unique Selling Points

- Combines action gameplay with tower defense strategy
- Fast-paced gameplay with shorter session times than traditional tower defense games
- Diplomacy system allowing for cooperation with former enemies
- Procedurally generated camp layouts
- Minimalist visual style with programmatically generated graphics

## Game Flow

1. **Survival Phase**: Players must survive initial waves from multiple camps simultaneously
2. **Conquest Phase**: Players strategically place towers to conquer enemy camps
3. **Cooperation Phase**: Players can complete quests to gain respect and cooperation from certain camps
4. **Final Phase**: Players confront and defeat the king

## Target Platform

The game is designed as a browser game using the Phaser framework, ensuring wide accessibility without requiring installation.

## Target Audience

- Casual gamers who enjoy tower defense but want shorter play sessions
- Players who enjoy strategic action games
- Browser game enthusiasts

## Development Goals

- Create a replayable tower defense experience with action elements
- Implement a working diplomacy system between player and enemy camps
- Provide a complete game flow from survival to king defeat
- Maintain a consistent, minimalist visual style
